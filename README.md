# Spotify Music Player

A custom Spotify-inspired music player created during the Bootcamp at Tipti by Majo Castro and Harshit.

## Description

This project is a fully functional music player built using JavaScript, HTML, and CSS. It features a collection of 30 favorite songs with a user-friendly interface that allows you to play, pause, skip forward, and skip backward through the playlist. The application also includes a secure login system where users can authenticate with their own password.

## Features

- **Music Playback Controls**
  - Play/Pause functionality
  - Skip to next song (forward button)
  - Return to previous song (backward button)
  - Progress bar showing current playback position

- **Song Management**
  - Library of 30 carefully curated favorite songs
  - Search functionality to find songs quickly
  - Autocomplete suggestions as you type
  - Add songs to "My Playlist"
  - Mark songs as favorites in "My Favourites"
  - Remove songs from playlists and favorites

- **User Authentication**
  - Secure login system with username and password
  - Logout functionality
  - Session management

- **Interactive UI**
  - Album cover display
  - Real-time song title and artist information
  - Responsive design using Bootstrap
  - Custom scrollable lists for playlists

## Technologies Used

- **HTML5** - Structure and layout
- **CSS3** - Styling and visual design
- **JavaScript** - Interactive functionality and music playback
- **jQuery** - DOM manipulation and event handling
- **Bootstrap 5.3.2** - Responsive design framework
- **Font Awesome 6.5.1** - Icons and visual elements

## How to Use

1. Open `Music Player.html` in your web browser
2. Click the "Login" button to access the login form
3. Enter your credentials (Username: `Majo Castro`, Password: `Music Player`)
4. Once logged in, you can:
   - Search for songs using the search bar
   - Click the play button to start listening to a song
   - Use the forward and backward buttons to navigate between songs
   - Add songs to your playlist using the plus icon
   - Mark songs as favorites using the heart icon
   - Remove songs from your lists using the minus or trash icons
